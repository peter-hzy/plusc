# 正式验收

## 可选的五家公司前向测试（不替代正式批次）

- 从全新仓库外 workspace 发起，不使用示例、fixture 或预写公司名单；
- 先主动发现超过五家候选，再按证据和匹配度保留五家；
- 使用未预先写答案的真实请求；
- 每家公司有归属当前 run 的 SourceRun、打开真实网页后形成的 Evidence、fit_reason 和 fit_status；
- 联系人标为 verified、supported、not_found 或 contradicted；
- 整批 proposed Claim 只暂停一次由真人审核，禁止用虚构 actor 绕过；
- 草稿可追溯到 Evidence 和已接受 Claim；
- 名单任务只要求公开相关对接入口，不强制个人邮箱或草稿；外联任务才要求一个实际可用渠道的原生草稿与单一CTA；
- “客户结果”单表7列，可查看联系理由、负责人或部门转交入口、渠道、关键缺口、文案和下一步；
- `research verify --scope companies`用于名单，`--scope outreach`用于外联；自动测试和`PRAGMA integrity_check`不能代替来源语义审核；
- 不发送消息，不把真实数据提交到仓库。

## 每批20家公司真实UAT

- 澳大利亚、新西兰优先；
- 核对去重、来源失败、联系人身份和话术自然度；
- 人工记录改稿原因；
- 由人工发送和回灌真实回复；
- 验证退订、投诉、重复回复和审批失效；
- 完成来源、联系人、话术和流程复盘。

无产品时只验证公司角色、来源与入口，不判产品适配。全量检查入选及排除理由；新旧搜索效果使用相同市场/产品/预算对照。历史名单回放不证明新搜索改善。渠道伙伴不计入买方配额，通用转交不算已确认商务负责人。

只有全新目录克隆安装、全部自动测试、公开仓库审计、Skill同步和本节真实UAT都通过后，才可以宣称达到正式生产验收。
