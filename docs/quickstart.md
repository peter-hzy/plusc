# 快速开始

1. 按 README 创建虚拟环境并安装 `[excel]`。
2. 用 `inbound-leads init --workspace <目录>` 创建私有工作区。
3. 填写产品与语气资料，运行 `context validate`。
4. 创建批次；默认正式目标为20—25家，也可用小样本先测试。
5. 使用主 Skill 制定多来源计划、主动发现候选公司，并用 `research coverage` 判断是否需要继续补搜。同一批次可以分多轮增量导入，系统按域名去重。
6. 对入选公司核验官网、负责人和联系入口，保存证据。
7. 人工接受 Claim 后生成两种渠道草稿。
8. 审核 Excel，批准后由人工发送；用 `reply ingest` 回灌回复。

没有付费 API 时，由 Codex 使用公开网页研究并通过 bridge 写入；手工导入只是兼容通道。不要为了填满名单而生成虚假数据。
