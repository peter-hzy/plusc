# 快速开始

1. 按 README 创建虚拟环境并安装 `[excel]`。
2. 用 `inbound-leads init --workspace <目录>` 创建私有工作区。
3. 填写产品与语气资料，运行 `context validate`。
4. 创建20—25家批次，导入候选公司。
5. 使用主 Skill 逐家公司研究、核验负责人并保存证据。
6. 人工接受 Claim 后生成两种渠道草稿。
7. 审核 Excel，批准后由人工发送。
8. 用 `reply ingest` 回灌回复，报价、会议、投诉和退订交给人工。

没有付费 API 时，使用公开网页与手工导入；不要为了填满名单而生成虚假数据。
