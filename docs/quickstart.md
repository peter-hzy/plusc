# 快速开始

1. 按 README 创建虚拟环境并安装 `[excel]`。
2. 用 `inbound-leads init --workspace <目录>` 创建私有工作区。
3. 有产品先填写产品资料；只有准备文案才要求语气资料。无产品用 `run create --research-only`，不填虚构信息。
4. 创建批次；默认不限行业（segments=*），目标20家独立公司。仅用户限定行业时设置segments。小样本只能验证流程，不替代20家交付。
5. 使用主 Skill 制定多来源计划、主动发现候选公司，并用 `research coverage` 判断是否需要继续补搜。同一批次可以分多轮增量导入，系统按域名去重。
6. 新研究使用service_fit_v1统一服务场景合同（见references/data-contract.md），核验真实业务信号、服务关联、合作假设、反证及下一步，逐字段绑定来源；部门和企业转交路径也可用，不强制个人负责人。
7. 导出单表七列Excel，用 `research verify --scope companies` 验收研究名单，不强制草稿。合作假设不冒充需求，缺入口明确待补查。
8. 用户需要外联且实际产品和事实已核准后，准备一个首选渠道草稿，按外联范围验收；审批与发送由人工完成，用 `reply ingest` 回灌回复。

没有付费 API 时，由 Codex 使用公开网页研究并通过 bridge 写入；手工导入只是兼容通道。不要为了填满名单而生成虚假数据。
