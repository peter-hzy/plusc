# 公司研究与证据协议

## 1. 目标

研究是把公开线索转成可复核的匹配公司和对接路径；澳新优先，其他市场按本批范围。每批固定20家公司。个人联系人只是入口之一，不要求采购决策人、采购意向或个人邮箱才能入选。

研究必须做到：

- 多来源发现，不能只依赖 LinkedIn、Google 或单一目录；
- 先确认公司，再寻找联系人；
- 搜索摘要负责指路，打开后的原始页面负责证明；
- 公司有中国/亚洲业务与公司现在有采购意愿必须分开；
- 找不到、没搜索、受限和冲突都要记录，不能静默空白；
- 每条输入最终进入正式名单、待研究、培育、不匹配或停止联系状态。

## 2. 运行前建立来源计划

先根据国家、客户类型和产品场景规划来源，不要直接漫无目的搜索。来源计划至少包含：

- `source_category`：官网、协会、展会、行业目录、LinkedIn、招聘、媒体、社交内容等；
- `source_role`：用于发现还是用于验证；
- `target_signal`：希望从该来源确认什么；
- `query_or_entry_url`：查询词或入口地址；
- `coverage`：国家、细分客户和语言；
- `access_status`：未搜索、已打开、没找到、来源受限；
- `contribution`：新增公司、新增联系人、新增证据、只重复已有内容或无贡献。

旅游行业查询不能只使用 `travel agency`。根据任务组合：

```text
China tours / Asia tours / long-haul / tailor-made / custom tours
group travel / educational travel / special-interest travel
luxury / adventure / family / senior / culture / food travel
corporate travel / incentive travel / MICE / event agency
supplier / contracting / product manager / destination manager
```

还应关注新增中国线路、亚洲产品招聘、展会参展、目的地合作伙伴招募、团组产品上线等时间信号。

查询矩阵按“市场 × 实际产品的客群/主题 × 公司角色 × 来源”展开。官网产品搜索、协会/展会、专业目录及已核实公司的公开伙伴用于发现；目录中所有旅行社不自动合格。同一公司进入后，优先读产品/目的地、合作、关于我们、团队和联系页，只补会改变匹配或对接决定的信息。

客户类型分布、候选池3倍及3类来源只是防漏提示，不是凑数或结束任务的硬门槛。每个来源记录新增且合格公司、重复、受限与失败。重复页不代表来源耗尽；服务错误不代表没有客户。连续没有合格新增时换查询或来源，不重复同一路径。

单家公司有足够主体、匹配依据和公开入口就停止深挖，不追求全部字段齐全。整批达到20家后做一次高价值对照搜索再择优、补关键缺口。不足时保留20目标，报告N/20及已尝试路径；只有扩大市场/产品等关键边界才询问。普通联系页是可研究入口，不等于已确认转交；没有入口的合格公司保留并标待补查，同时单列已找到入口数量。

未入选候选也必须进入 `CandidatePool`，并标明 `candidate_pool`、`held` 或 `excluded` 及原因。只有保存整个候选池，才能复查是否搜窄、误删或漏掉公司。

## 3. 来源等级

### A：优先正式证据

- 公司官网的产品、团队、合作、目的地和联系页面；
- 协会会员目录和展会官方参展商资料；
- 公司新闻稿、正式业务资料；
- 本人公开职业资料或本人邮件签名。

### B：可靠辅助证据

- LinkedIn 公司页和公开职业资料；
- 公司官方社交账号；
- 招聘页、活动演讲者资料、可靠行业媒体和公开采访；
- 经过核验的专业商业目录。

### C：只用于发现

- 搜索摘要；
- 聚合目录、转载内容；
- YouTube、TikTok、Facebook、Instagram、Reddit 等普通公开内容；
- 点赞、播放、粉丝、泛评论和没有业务上下文的互动。

### X：不能升级

- 页面无法打开或来源已失效；
- 多个来源相互冲突；
- 疑似私人或敏感个人信息；
- 无法确认指向同一家公司或同一个人。

C 级来源可以发现公司或负责人候选，但关键公司结论和联系人身份至少需要 A/B 来源支持。只有 C 级来源时，保持 `candidate_pool` 或 `research_needed`。

## 4. 两层名单

### L1 候选池 `candidate_pool`

满足任一条件即可进入：

- 来源表明它可能属于目标客户类型；
- 经营亚洲、长线、定制、团组、商务或 MICE 产品；
- 出现潜在中国相关信号，但尚未完成核验。

候选池允许资料不完整，但必须保存发现来源和观察日期。

### L2 正式研究名单 `formal_list`

必须同时满足：

1. 公司官网或其他 A/B 来源确认公司主体；
2. direct/expansion路径有A/B级证据证明出境销售角色；channel路径证明相关客源组织或转介能力，不冒充买方；
3. direct有中国/相邻产品依据；expansion/channel允许没有China关键词，但必须有客群依据、合作假设、反证与下一步；
4. 记录它可能使用外部中国地接、合作路径不明、或已有自营地接，不能把“经营中国游”直接写成采购需求；
5. 记录它是潜在买方、业务混合、竞争者或关系未知；一体化竞争者不能进入优先联系；
6. 有可以解释联系原因的真实业务依据，没有未解决的主体冲突或停止联系信号；
7. 记录至少一名主要联系人，或明确记录已搜索但没找到并保留转交入口。

最终入选公司必须填写四个门禁字段：

- `source_market_role`：`outbound_seller` / `channel_partner` / `unclear` / `not_source_market`；
- `china_product_signal`：`direct` / `adjacent` / `none`；
- `ground_partner_route`：`external_partner_possible` / `unclear` / `in_house`；
- `competitive_position`：`potential_buyer` / `mixed` / `competitor` / `unknown`。

`qualification_path=direct`沿用outbound_seller和中国direct/adjacent门槛。expansion允许china_product_signal=none但必须为outbound_seller；channel必须为channel_partner。后两者必填audience_fit、cooperation_hypothesis、counter_evidence、next_action，只能作为待确认chat_candidate，不自动升优先。旧批次未填路径按direct兼容，不自动重新判定合格。若用户要20家买方，不能以channel补数；渠道路径仅在合作公司范围适用。

`formal_list`是研究名单，不是“有购买意愿”或“允许发送”。产品未提供时仅有通用业务匹配；名单验收与产品匹配、触达准备分别报告。

已有供应商不等于没有机会；仅在能说明实际互补区域/产品时提出合作。未知外部合作路径保留chat_candidate或research_needed，不能仅凭缺证据排除。优先研究与我方真实区域、团型、语言和接待能力吻合的客源方。MICE和专项团仅在我方能力获确认后进入目标范围。

其他研究阶段：

- `held`：因身份冲突、来源受限或重要缺口暂缓；
- `excluded`：明确不匹配或不得联系。

## 5. 每家公司必须回答

1. 公司主体、官网、国家和客户类型是什么？
2. 它向谁销售什么旅游产品？
3. 是否存在中国、亚洲、长线、定制、团组、企业差旅或 MICE 信号？
4. 哪个信号是事实，哪个只是合作假设？
5. 我们当前已确认的产品能力与哪个业务场景相关？
6. 为什么联系这个人，而不是只找最高职位？
7. 哪些资料未知、没找到、来源受限或存在冲突？
8. 是否命中重复记录或停止联系规则？
9. 它是目标市场的客源方，还是当地入境地接/同行？
10. 它使用外部中国地接的依据是什么；若未知，是否已降级而非写成采购意向？

## 6. 证据记录

每个独立来源观察写入一条 `Evidence`：

- `entity_type`、`entity_id`；
- `supported_field`；
- `evidence_kind`；
- `fact_summary`；
- `source_url`；
- `source_tier`；
- `source_role`；
- `source_access_status`；
- `source_published_at`（如有）；
- `observed_at`；
- `evidence_status`；
- `conflict_note`。

同一页面出现多个字段仍属于一个独立来源。可以让一条证据支持一个主要结论并在摘要中补充其他信息，但不能复制成多条提升可信度。

## 7. 联系人研究

联系人选择依据公司规模和业务：

- 小公司：Owner、Founder、Managing Director；
- 产品型旅行公司：Product、Contracting、Purchasing、Destination；
- 中国/亚洲专线：China Specialist、Asia Product；
- 团组和会展：Groups、MICE、Events、Incentives；
- 合作入口：Partnerships、Business Development；
- 只能转交：公开业务邮箱或一般联系入口。

每家公司默认一名 `primary`，必要时一名 `backup` 或 `handoff`。禁止为了增加触达量同时准备多名同公司联系人发送。

联系人身份核验必须读取 `identity-matching.md`。

## 8. 状态与冲突

来源访问状态：

```text
not_searched
opened
searched_not_found
source_restricted
```

证据状态见 `data-contract.md`。以下情况必须保持 `held` 或 `research_needed`：

- 公司同名但域名或国家无法确认；
- 联系人姓名、现任公司或职位冲突；
- 个性化依据只有搜索摘要；
- 联系理由依赖未确认的产品能力；
- 关键来源无法访问且没有替代来源。

冲突不能靠增加更多弱来源“投票”消除。必须找到更直接的来源或交给人工判断。

## 9. 完成一次研究的输出

一次公司研究必须产生以下之一：

- 正式公司和联系人记录；
- 候选记录及明确的下一步研究缺口；
- 已搜索但没找到的状态；
- 来源受限状态；
- 冲突及人工判断请求；
- 不匹配或停止联系记录。

不得返回只有公司名称、没有来源和状态的“名单”。

## 10. 扩展发现、反查与实际运行

按本批市场×角色×真实产品主题×来源×适用语言选高相关组合，不穷举。除China tours外，检查文化/专项/长线客群、批发与顾问网络、公开合作伙伴和新产品信号。协会/展会是发现源，成员和展商不自动是客户；学校、协会等非公司不计公司名额。登记品牌/集团关系；同采购入口的多品牌不凑数。

连续两轮无合格新增时换查询或来源；失败/限速不计无客户。每轮记录结果、耗时、下一入口和已执行范围；来源计划contribution可保存简洁断点说明。coverage执行结果统计区分成功、无结果、受限和失败，但目前不自动调度浏览器。预算只是进度检查点，不为凑时间提前宣称完成或擅自扩市场。

普通搜索定位，原站核验；动态目录才使用可用浏览器Skill/工具。先验证运行连接，读取当前页面后操作过滤/分页，每次交互核对状态，保留最终URL、相关摘录、日期和必要截图。目录空白不等于无公司。遇限制换公开来源，不绕过登录/验证码、不上传用户会话数据。可用工具替代失败工具时明确记录，不声称原工具已修好。

交付前逐家看反证，检查所有被硬排除候选的原因；不能以统计PASS代替语义复核。观察超过90天、人员/入口超过30天应重新核实（内部默认提醒，不是行业有效期）；发送前再次检查。新旧规则的同池比较检验筛选，等预算新搜索才检验发现能力。无产品不得声称精准匹配改善。
